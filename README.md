# 🚑 Ambulance Traffic System

A smart emergency response management solution built with Python & SQLite.

## Features

- Emergency & ambulance management
- Real-time status tracking
- Fleet control with driver assignments
- SQLite database

## Quick Start

```bash
python main.py
```

Menu: Add ambulance (1), View ambulances (2), Update status (4), Delete (5), Register emergency (6), View emergencies (7), Exit (3)
