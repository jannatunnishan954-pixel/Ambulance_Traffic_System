# 🚑 Ambulance Traffic System

> A smart emergency response management solution built with Python & SQLite

![Python](https://img.shields.io/badge/Python-3.x-blue?style=flat-square) ![Database](https://img.shields.io/badge/SQLite-Active-success?style=flat-square)

## ✨ Features

- 🚨 Emergency & ambulance management
- 📍 Real-time status tracking
- 🏥 Fleet control with driver assignments
- 💾 Persistent SQLite database
- 🎮 Simple CLI interface

## 🚀 Quick Start

```bash
python main.py
```

**Menu Options:**
- `1` – Add ambulance
- `2` – View ambulances
- `4` – Update ambulance status
- `5` – Delete ambulance
- `6` – Register emergency
- `7` – View emergencies
- `3` – Exit

## 📊 Database Tables

**Ambulances:** id, driver_name, hospital, current_location, status

**Emergencies:** id, patient_name, location, priority, status
